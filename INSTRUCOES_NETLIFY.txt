🚀 INSTRUÇÕES PARA DEPLOY NA NETLIFY & FIREBASE (LESTEK)

=====================================================
📌 SOBRE A MENSAGEM DO FIREBASE STORAGE ("Fazer upgrade do projeto")
=====================================================
O Firebase passou a exigir o plano "Blaze (Pay-as-you-go)" para criar o bucket do Firebase Storage em novos projetos.

Sua aplicação possui DUAS OPÇÕES para utilizar imagens e logos:

OPTION 1: MODO AUTOMÁTICO SEM CARTÃO / SEM UPGRADE (JÁ CONFIGURADO!)
- O aplicativo conta com compressão automática inteligente.
- Quando você faz upload da Logo ou de imagens de produtos, o app comprime a imagem e salva diretamente no Firestore.
- Você NÃO PRECISA ativar o Firebase Storage nem cadastrar cartão no Firebase!

OPTION 2: USAR O FIREBASE STORAGE OFICIAL
- Se preferir usar o Storage do Firebase, clique em "Fazer upgrade do projeto" no console.
- Selecione o plano Blaze (o Firebase oferece 5 GB/mês gratuitamente, você só paga se exceder o uso gratuito).
- Na aba 'Storage' -> 'Rules' (Regras), cole:
  rules_version = '2';
  service firebase.storage {
    match /b/{bucket}/o {
      match /{allPaths=**} {
        allow read: if true;
        allow write: if request.auth != null;
      }
    }
  }

=====================================================
1. NO FIREBASE (CONFIGURAÇÃO BÁSICA NECESSÁRIA)
=====================================================
- Ative o 'Firestore Database'. Na aba 'Rules' (Regras), cole:
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /{document=**} {
        allow read: if true;
        allow write: if request.auth != null;
      }
    }
  }
- Ative 'Authentication' -> 'Email/Password' e crie seu usuário admin (email e senha).

=====================================================
2. NA NETLIFY
=====================================================
- Faça o upload da pasta 'dist' (gerada após o comando 'npm run build').
- Em 'Site Settings' > 'Environment variables', adicione:
  VITE_FIREBASE_API_KEY
  VITE_FIREBASE_AUTH_DOMAIN
  VITE_FIREBASE_PROJECT_ID
  VITE_FIREBASE_STORAGE_BUCKET
  VITE_FIREBASE_MESSAGING_SENDER_ID
  VITE_FIREBASE_APP_ID
  GEMINI_API_KEY = (Sua chave da Google AI Studio, se desejar)

=====================================================
3. ACESSO AO PAINEL ADMINISTRATIVO
=====================================================
- Acesse a rota '/admin.html' no seu site.
- Utilize o e-mail e a senha criados no Firebase Authentication.

Tudo pronto para decolar! 🚀
