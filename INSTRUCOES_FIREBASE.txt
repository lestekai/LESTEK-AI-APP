⚠️ REGRAS DO FIRESTORE (CORREÇÃO DE VISIBILIDADE) ⚠️

Para que todos os visitantes consigam ver as informações do seu site sem precisarem estar logados no painel de admin, você precisa atualizar as Regras de Segurança (Security Rules) do Firestore no seu Firebase Console.

PASSO A PASSO:
1. Acesse o Firebase Console (console.firebase.google.com).
2. Selecione o seu projeto ("Lestek" ou o nome que você deu).
3. No menu lateral esquerdo, clique em "Firestore Database".
4. Vá até a aba "Regras" (Rules).
5. Apague tudo o que estiver lá e cole EXATAMENTE o código abaixo:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Permite que qualquer pessoa leia os dados do site (produtos, serviços, textos)
    match /site_content/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /services/{serviceId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /products/{productId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    // Bloqueia qualquer outra coleção não especificada por padrão
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

6. Clique no botão "Publicar" (Publish).

SOBRE O AVISO DE BANCO NÃO CONFIGURADO:
Se você vir o aviso "⚠️ ATENÇÃO: O banco de dados não está configurado" aparecer quando abrir o seu site no Netlify, significa que você ainda não colocou as "Environment Variables" (Variáveis de Ambiente) lá no painel do Netlify!
Para o banco de dados funcionar no Netlify, você DEVE ir em Site Configuration > Environment Variables, e colar todas as chaves (VITE_FIREBASE_API_KEY, etc.) igual estão no arquivo .env.example.
